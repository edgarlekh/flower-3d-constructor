# Пайплайн моделей

Черновик. Наполняется на Этапе 3.

## Идея

Фото товара → 3D-модель (GLB) → компактный JS для быстрой загрузки в браузере.

## Шаги (план)

1. **`scripts/generate-models.py`** — прогон фото через TRELLIS 2 / Meshy,
   на выходе GLB.
2. **`scripts/pack-model.py`** — GLB → компактный JS (base64). Скрипт готов в
   прототипе, переносится как есть.

## Важно про текстуры

Для моделей из TRELLIS/Meshy в three.js обязательно `texture.flipY = false` —
иначе развёртка ложится зеркально. В прототипе баг уже отловлен, не повторять.

## Модель — безразмерная

Пайплайн нормализует геометрию и считает пропорции (`neck_ratio`,
`width_ratio`). Реальный размер (`height_cm` и т.п.) вводится вручную в
`catalog.js` — одно число, остальное из пропорций.
