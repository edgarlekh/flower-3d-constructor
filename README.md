# flower-3d-constructor

Веб-инструмент, который показывает паре или декоратору, как будет выглядеть
свадебный цветочный декор, и сразу считает цену. Позже — расстановка в 3D-зале
и интерактивный показ заказчику.

**Живой адрес:** https://flower-3d-constructor.pages.dev

## Что внутри

Чистый фронтенд без сборщика: HTML + JS + three.js (r128). Хостится на
Cloudflare Pages, деплой из корня репозитория — любой push в `main`
автоматически публикуется.

## Два незыблемых принципа

1. **Ручная расстановка** — пользователь берёт каждый цветок и ставит туда,
   куда хочет. Автосборка даёт только стартовый вариант.
2. **Реальные сантиметры** — сцена живёт в см, каждый объект несёт реальные
   габариты. Размер задаётся вводом одного числа, остальное — из пропорций.

## Структура

```
index.html          лендинг
constructor.html    конструктор букета (ядро)
assets/
  css/              стили
  js/               движок раскладки, камера, загрузчик моделей, UI каталога
  catalog/          данные каталога (catalog.js) и модели (.glb → .js)
scripts/            Python-пайплайн подготовки моделей (не деплоится)
docs/               концепция, архитектура, пайплайн моделей
data/               исходники фото и моделей (в .gitignore)
```

## Дорожная карта

- **Этап 0** — скелет и лендинг ✅ *(текущий)*
- **Этап 1** — перенос конструктора букета из прототипа v14
- **Этап 2** — ручное перетаскивание цветов (главная фича MVP)
- **Этап 3** — пополнение каталога через пайплайн моделей
- Этап 4+ — 3D-зал, показ заказчику, арки *(не в MVP)*

Подробности — в [docs/concept.md](docs/concept.md).
